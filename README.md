# Math Foundations for Machine Learning — Made Easy

A short, practical book on the three areas of math you actually need for machine
learning: **linear algebra**, **calculus**, and **probability & statistics**.

**Read it here: https://astromar96.github.io/ml-math-book/**

Written for anyone heading toward a junior ML engineer role who finished
high-school math (or forgot most of it). No proofs, no heavy theory. Every topic
goes: intuition in plain words → the formula → a worked example with real
numbers → why ML cares → practice problems (answers in the back). Key ideas are
also explained in Egyptian Arabic.

## Contents

| Chapter | Topic |
| --- | --- |
| 1 | Math warm-up: notation, functions, exponents, logs, Σ |
| 2 | Linear algebra: vectors, dot product, matrices, transpose, inverse, eigenvectors |
| 3 | Calculus: derivatives, partial derivatives, gradient, chain rule, gradient descent |
| 4 | Probability: basics, conditional probability, Bayes, distributions |
| 5 | Statistics: mean/variance, correlation, sampling, hypothesis testing |
| 6 | Putting it together: linear regression from scratch, by hand and in NumPy |

Plus an answer key, a one-page cheat sheet, and an 8-week study plan.
